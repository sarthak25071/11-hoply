Design a modern, premium, Figma-style UI/UX case study for a web application called "Hoply".

Hoply is a travel companion platform that helps travellers heading to similar destinations find each other and mutually agree to share a taxi. Think of it as a combination of Uber, Tinder, and LinkedIn—but for airport travel companions.

Create a single large Figma presentation board (dribbble/behance style) showing every major screen laid out beautifully with annotations and consistent spacing. The design should look like a professional startup product created by an experienced UI/UX designer.

Style:
- Modern SaaS UI
- Glassmorphism with subtle shadows
- Rounded corners (16–20px)
- Clean typography (Inter)
- Soft gradients
- White background with green (#22C55E) and blue (#2563EB) accents
- Premium minimal design
- Apple + Airbnb + Linear + Uber inspired
- Responsive desktop web app
- High fidelity UI
- Consistent design system
- Beautiful cards, icons and illustrations
- Map illustrations where appropriate
- Realistic user avatars
- Airport themed illustrations
